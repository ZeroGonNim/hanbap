# AI Development Prompt Template

## 1. Task

구현해야 할 기능을 설명한다.

예시
- 사용자 로그인 기능 구현
- API 호출 후 사용자 목록 표시
- Zustand 상태 관리 적용

---

## 2. Requirements

필수 요구사항

- React + TypeScript 사용
- Tailwind CSS 사용
- 상태 관리는 Zustand
- any 타입 사용 금지
- 코드 가독성 우선

---

## 3. Context

현재 프로젝트 상황 설명

예시

- React + Vite 프로젝트
- Zustand store 이미 존재
- API는 REST 방식

---

## 4. Expected Output

AI가 제공해야 할 결과

- 실행 가능한 코드
- 필요한 yarn 명령어
- 코드 설명

응답 형식

1. 결론
2. 코드
3. 설명

---

## 5. Constraints

제약 사항

- 기존 구조 유지
- 파일 구조 변경 금지
- 불필요한 라이브러리 추가 금지
